# 角色一致性与人物资产

目标：同一个人物在设定图、分镜图、视频参考之间看起来是**同一个人**。
漂移几乎都来自三件事：一张图里塞了太多要求、参考图不是母版、以及反复迭代同一张图。

## 1. 五条总原则

1. **母版一张图**：角色母版是**一张图**，不是“一张脸 + 一张身体”两个资产。
   身体和面部特写放在同一块画布上，一起生成、一起引用。
2. **一次只改一个变量**：换装、受伤、妆造、年龄分开做，不要在同一次生成里改两件事。
3. **单图承载**：每多拆一个资产，就多一次“这两张到底是不是同一个人”的对齐机会。
   下游只引用这一张母版图。
4. **派生不迭代**：变体永远引用母版，不引用上一版变体，避免误差累积。
5. **只写看得见的**：提示词只描述参考图里真实存在的特征，不补写没有依据的五官、材质和道具。

## 2. 母版图：一张画布，两个面板

版式固定成左右两块，背景、光线、肤色在整个画面里是同一套：

```
+---------------------------+------------------+
|                           |                  |
|   身体面板（锁骨以下）      |   面部特写面板     |
|   正面或 3/4、自然站姿      |   正脸、平视       |
|   约 55% 宽度              |   约 45% 宽度      |
|                           |                  |
+---------------------------+------------------+
```

- **身体面板**：构图从锁骨以下开始，**头部不入画**。只负责体型、比例、肩宽、肤色、服装轮廓。
- **面部特写面板**：正脸或轻微 3/4、平视、中性表情、无遮挡。负责身份。
  放在同一张 `2k` 图里，面部实际像素仍然够用，不会像全身图里那样被稀释。
- **一次生成**：一个 `create_image` 调用出这一张图，不要拆成两次。
- **两个面板共用同一光源、同一背景、同一肤色**，这是同一张图相对两张图的最大优势。
- **头部不入画只是取景**：不要写 `headless`、`decapitated`、`severed head`，
  也不要在身体面板画颈部断面。画面直接从锁骨开始，颈部本来就在画外，不会像受伤。

提示词骨架：

```
character reference sheet, one single image, two panels on a neutral 18% gray background,
left panel: costume and body reference from the collarbone down, head out of frame,
front view, natural standing pose, same skin tone;
right panel: close-up headshot of the same character, eye level, neutral expression,
facing camera, visible skin texture;
both panels share the same soft even lighting and the same person,
no blood, no injury, no severed neck, no text
```

生成后先看这一张：两个面板像不像同一个人、光是否一致。不像就重做这一张，
不要分别去修两个面板，也不要把两张图拼起来。

## 3. 眼神光：柔和、自然、小面积

眼神光是跨图一致性的高频破绽——它的位置和形状一变，观众立刻觉得“不是同一个人”。

- 用**柔和的单点高光**，方向与主光一致，面积小到能看见瞳孔纹理。
- 禁止环形灯：会在瞳孔里留下环形光斑，角色一转角度就对不上。
- 禁止彩色高光/彩色补光：红蓝边缘会串到下一镜，污染肤色和道具颜色。
- 禁止大面积柔光箱直怼：高光糊成一片，眼睛没有神。
- 双眼高光位置要对称但不机械，符合真实光源。
- 戴眼镜时高光落在镜片而非瞳孔，另写一句控制镜片反光；不要让镜片反光遮住眼睛。

提示词里显式写禁用项，比只写“自然眼神光”更可靠：

```
small soft natural catchlight consistent with the key light; no ring light, no colored highlights,
no large specular bloom over the iris
```

## 4. 灰底与肤质

母版图就是设定图，它的光线和背景必须稳定、可复现，否则变体之间没法比对。

- **背景**：中性灰（约 18% 灰），无渐变、无纹理、无道具、无文字、无水印。
- **光**：均匀柔光，正面略高，阴影浅而柔；身体和面部两个面板共用同一光位。
- **皮肤**：保留毛孔、细纹、痣、疤痕等真实纹理；禁止磨皮、美颜、塑料感、过度锐化。
- **表情**：中性，方便后续做表情与口型参考。
- **分辨率**：`2k`；发丝、皮肤、服装材质要能看清。
- **文字**：不要在画面里写字标注“正面/侧面”，用资产名称区分；画面文字会污染参考。

## 5. 状态变体：换装、受伤、妆造、年龄

变体是“同一张母版图 + 一个变化”，版式保持完全不变。

- **引用母版**：`refs` 放这张母版图的资产 id；不要以上一版变体作为参考。
- **保持双面板版式**：变体仍然一张图、同样的左右布局、同样的灰底和光位，方便逐像素比对。
- **单变量**：换装只改服装；受伤只加伤口；妆造只改妆面。一次改两件，评审时分不清是哪一步漂了。
- **只描述变化区域**，其余显式锁定：
  `keep the layout, face, hairstyle, body proportions, skin tone, pose, camera angle,
  background and lighting identical to the reference; change only the jacket`.
- **母版不动**：变体登记为独立资产，命名 `角色-状态-版本`（如 `linwan-injured-v1`），母版保持原名。
- **受伤**要写清位置、面积、新旧程度、是否影响发型/服装/妆面；伤口不能出现在下一镜不该有的位置。
- **换装**默认保留体型、姿态、肤色、发型；如果变量就是发型，就不要再同时改服装。

## 6. 工具与参数（Filmline）

- `create_image` 一次出母版图；`refs` 里放需要延续的既有资产（最多 10 张）。
- 分辨率：母版图、状态变体用 `2k`；构图试错、动作草稿用 `1k`。
- 比例：母版图用 `1:1`（左右双面板最稳）；如果目标画幅是竖屏，可用 `9:16` 改成上下布局。
- 固定 `seed` 做 A/B 对比；`count > 1` 只用于挑一版，**选定后以选中版为新母版**，未选中的不要继续派生。
- 素材属于某一集时传 `episode`，避免产物落在项目级；放错位置用 `move_assets` 迁回。
- 生成是异步任务：提交后等完成通知，或用 `read_image` / `get_asset` 核对结果；不要凭提示词假设成功。

## 7. 与视频提示词的衔接

- 母版图作为**一张** `<Picture N>` 引用，不要拆成脸和身体两个引用。
- 在 `subject_definitions` 里写清两个面板的职责：
  `appearance and identity come from the face panel of <Picture 1>;
  body proportions and costume come from the body panel of <Picture 1>`。
- 一个 `<Subject N>` 只对应一个真实人物；多面板设定图只建这一个 Subject，其余面板是设计参考。
- 全能参考的图片上限是 9 张，同一角色只带当前镜头需要的状态（日常/受伤/换装不要一次全放）。
- 状态在镜头间变化时，用不同 `<Picture N>` 对应不同状态的母版图，并在 `retention_analysis` 说明保留关系。
- 视频里出现“脸不像同一个人”时，先查参考图是不是母版、脸在母版里是否够大，再改提示词。

## 8. 交付前自检

1. 母版是**一张图**，身体面板与面部特写面板在同一块画布上，不是两个资产。
2. 两个面板是同一个人、同一套光、同一个灰底。
3. 身体面板头部不入画，没有颈部断面、血迹或血腥效果。
4. 面部特写在 `2k` 下清晰，能看到瞳孔纹理与皮肤细节。
5. 眼神光柔和、单点、方向一致；没有环形灯、彩色高光、大面积光斑。
6. 皮肤有真实纹理，没有磨皮感、塑料感。
7. 变体只改了一个变量，版式、光位、背景与母版一致。
8. 变体命名能看出角色、状态、版本，母版未被覆盖。
9. 放进视频提示词时只引用一张 `<Picture N>`，一个 `<Subject N>` 对应一个人，面板职责写清楚了。
10. 结果已经实际查看过，不是只凭提交成功就当作完成。
